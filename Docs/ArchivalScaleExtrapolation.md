## 二、外推模型

流式管线（分页拉取 → 100 行/批 → 落盘）的内存特征是**批级常量**：峰值由
"当前页 + 当前批 + 文件缓冲"决定，不随总行数线性增长。因此：

- **流式外推（预期）**：峰值 ≈ 千万档实测值 + 缓冲增长项。缓冲增长主要来自
  文件句柄与累计计数器，量级 < 1 MB/亿行，可忽略。亿行峰值预估：
  MySQL ≈ 62 MB（+ε），PostgreSQL ≈ 78 MB（+ε）。
- **线性外推（上界校验用）**：若实现错误退化为整体物化，峰值 ≈ 62 MB × 10 = 620 MB（亿行），
  已逼近 1200 MB 封顶；10 亿行时 ≈ 6.2 GB，必然 FAIL。该模型用于反推：
  **封顶护栏在亿行档即可拦截物化退化**，10 亿行档必拦。

## 三、结论

1. 流式路径亿行存档内存峰值预估 62–78 MB 量级，远低于 1200 MB 封顶，**外推通过**。
2. 置信度：中。依据为同代码路径双引擎千万档实测；放大 10 倍后批级常量假设待实测确认。
3. 准出动作：本版（2.0.0）出包**不包含**亿行实际造数存档（b539d4d 口径）；
   后续版本在真机窗口以 `dotnet run -c Release --project Tests/TaoDBM.ScaleProbe -- export-sync 100000000`（亿行档）
   实测补账，并入 M4 准出清单。
