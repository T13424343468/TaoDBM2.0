定义预览｜存储过程 sp_settle_daily
接线：目录查询结果 → 定义/DDL 面板
CREATE PROCEDURE sp_settle_daily(IN p_date DATE)
BEGIN
  UPDATE orders SET status = 'settled'
  WHERE pay_date = p_date AND status = 'paid';
END
点开节点即取定义；右上角「打开到查询窗口」可一键载入 SQL 编辑器。

🔒 数据安全设计专节
  • 危险操作预览+确认：右键「重命名 / 删除」只生成语句草稿，执行前弹出预览，展示完整 SQL 与影响对象清单。
  • 可回滚/可审计：DROP/ALTER 类操作记录到操作历史（时间、账号、语句），支持导出；元数据查询全部为只读 SELECT。
  • 最小权限：树目录查询使用当前连接账号自身权限，看不到的无权对象自然不展示。
