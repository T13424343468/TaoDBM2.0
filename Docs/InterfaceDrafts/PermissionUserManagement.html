用户与权限管理

用户名@主机 全局权限 库级授权 高危权限 操作

权限矩阵

勾选即改，保存时生成一条完整的授权 / 回收语句，先预览后执行。

权限 app_rw@% reader_a@10.% 说明
SELECT✔✔读
INSERT / UPDATE / DELETE✔—写
DROP / TRUNCATE——高危：操作前需预览+二次确认
GRANT OPTION（转授）——高危：仅宽账号出现

数据安全设计专节

  • 危险操作预览+确认：授权 / 回收不直接执行，先弹出即将生成的 GRANT / REVOKE 语句供核对，点击确认才生效。
  • 可回滚 / 可审计：每次权限变更写入审计记录（时间、账号、语句、操作者），一条 REVOKE 可用同界面逆向恢复为 GRANT。
  • 凭据不落盘：新建用户的密码仅在创建弹窗内展示一次并加密连接提交，不留明文缓存，不写入连接配置文件。
  • 最小权限：界面默认按需勾选，宽账号（ALL）与可转授账号单独标红提示，避免随手复制过宽授权。
