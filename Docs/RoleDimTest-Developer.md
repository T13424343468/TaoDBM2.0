# 真实角色维度测试清单：日常开发者

> 视角设定：每天用数据库工具干活的后端开发，关心的是建表改表顺手、查数快、备份省心、危险操作有确认。
> 环境要求：云真机已装 2.0，准备一张有数据的 MySQL 测试库。

## 流程一：建表改表

| # | 步骤 | 预期结果 | 判定标准 |
|---|------|---------|---------|
| 1 | 右键表区「设计表」，新建一张表加 3 个字段 | 表单能保存 | 字段类型下拉可选，主键能设，保存无报错 |
| 2 | 对象树里点「设计表」改字段类型、加索引 | 改动生效 | 回到对象树刷新可见新结构 |
| 3 | 改完直接关窗再重开 | 改动还在 | 重启后结构与改后一致 |

## 流程二：问库（中文查数）

> 现状如实说明：问库引擎（规则层）已就绪，**界面入口还未开放**，本步骤先以规则层实测代替，入口开放后补真机点选走查。

| # | 步骤 | 预期结果 | 判定标准 |
|---|------|---------|---------|
| 1 | 用一句中文问数（如「上个月订单量多少」） | 规则层给出 SQL | 生成 SQL 语法正确 |
| 2 | 结果预览确认后才执行 | 只读预览 | 未确认前不真正执行 |
| 3 | 同句再问一次 | 走本地问答记忆 | 第二次响应更快 |

## 流程三：备份计划

| # | 步骤 | 预期结果 | 判定标准 |
|---|------|---------|---------|
| 1 | 库右键「备份计划」新建每日备份 | 计划创建成功 | 列表出现该计划，可改可删 |
| 2 | 手动触发一次备份 | 备份文件生成 | 文件落盘且大小合理 |
| 3 | 用备份还原到新库 | 还原成功 | 新库表结构与源一致 |

## 流程四：危险 SQL 预览确认

| # | 步骤 | 预期结果 | 判定标准 |
|---|------|---------|---------|
| 1 | 跑一句不带 WHERE 的 UPDATE | 弹确认框 | 有预估影响行数，不点确认不执行 |
| 2 | 跑 DROP TABLE / TRUNCATE | 弹确认框 | 明确警示危险级别 |
| 3 | 点「仅预览不执行」 | 什么都不发生 | 确认退出后数据无变化 |

## 真机走查步骤＋截图要求

1. 按流程顺序走，重点截：设计表单、问库预览、备份计划列表、危险 SQL 确认框。
2. 危险 SQL 那组必须截「确认弹窗」和「仅预览后数据不变」两张作证。
3. 每步标注判定结果；不符预期的截图带上下文（上一步操作也在画面里）。
4. 云端执行时若问库界面入口仍未开放，本条按规则层实测结果记录，不算走查失败。
