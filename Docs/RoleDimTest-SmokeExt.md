# 角色清单云端冒烟自动化扩展建议

> 定位：给现有 ui-smoke 环节的扩展建议，**不改 WindowsBuild.yml、不动主链**。三份角色清单中能在云端自动化的，按下面优先级逐步加。

## 可自动化且建议先做（低风险高价值）

| 来源 | 步骤 | 自动化方式 | 预期 |
|------|------|-----------|------|
| 新手·流程一 | 装 MSI 后真启动 | 已有 ui-smoke 覆盖 | 保持不动 |
| 新手·流程二/三 | 主窗口出现后菜单可达性 | 启动后按快捷键/菜单点开「新建连接」，截图确认表单弹出 | 表单窗口句柄存在，无崩溃 |
| 新手·流程三 | 对象树空状态 | 不建连接直接看对象树 | 空态提示文案出现，不白屏 |
| DBA·流程三 | 分片向导打开 | 菜单点开向导对话框，截首屏，关闭 | 对话框打开且可关闭，进程存活 |
| DBA·流程一/二 | 各诊断对话框能打开不崩 | 依次打开诊断/热点/再均衡对话框 | 全部能开能关 |

## 可自动化但需准备数据（中优先级）

| 来源 | 步骤 | 前提 | 方式 |
|------|------|------|------|
| 新手·流程四 | 简单查询出结果 | 云端有本地 MySQL | 建连接后跑 SELECT，断言返回行数 |
| 开发者·流程一 | 设计表单打开保存 | 同上 | 新建表走完整保存流 |
| 开发者·流程四 | 危险 SQL 确认框 | 同上 | 触发无 WHERE UPDATE，断言弹窗出现且未执行 |

## 建议保持人工/半自动（不进冒烟）

- 新手·流程五导出文件内容抽查（需要人工看文件）；
- DBA·流程一死锁环现场（需并发会话编排）；
- 开发者·流程二问库（界面入口未开放，规则层已由 LogicTest 覆盖）。

## 接入方式

扩展步骤放 ui-smoke 之后新增独立 job（如 `role-smoke`），失败不阻塞主链，产物只传截图与判定 JSON；等三份清单各跑过一轮、判定稳定后再考虑是否收紧为硬闸。
