1. 安装与卸载

系统要求

· 操作系统：Windows 10 1809 及以上版本或 Windows 11，64 位（x64）。

· 运行时依赖：安装包不内置 .NET 运行时；若系统缺失，安装器会检测并引导联网安装到统一目录，按提示完成即可。

· 磁盘空间：建议预留 500 MB 以上；连接远程数据库时本机资源占用很小。

· 权限：安装需要管理员权限（MSI 写入 Program Files）；日常使用不需要管理员身份。

安装步骤

1. 双击安装包（TaoDBM x64 MSI）启动安装向导。

2. 按向导选择安装目录（默认即可），点「安装」。

3. 安装完成后从开始菜单或桌面快捷方式启动 TaoDBM。

！若安装器提示缺少 .NET 运行时，按引导联网安装后再继续，装完无需重启即可使用。

升级与覆盖安装

· 新版本安装包可直接覆盖安装：向导会沿用原安装目录，完成后启动即是新版。

· 覆盖安装不影响已保存的连接配置与界面布局，无需重新配置。

· 大版本升级前如有重要数据操作，建议先照常备份（见「备份与恢复」章）。

卸载

· 方式一：「设置 → 应用 → 已安装的应用」中找到 TaoDBM，点「卸载」。

· 方式二：控制面板 → 程序和功能 → 选中 TaoDBM → 卸载。

· 卸载只移除程序本体；连接配置等个人数据保存在数据根目录，卸载不会自动删除，重装后仍在。

· 数据根目录位置：优先 D:\TaoDBMData\TaoDBM（D 盘可用时自动使用）；D 盘不可用时回退到 %LOCALAPPDATA%\TaoDBM。彻底清理请两处都检查，删你实际在用的那处（不确定就都看一眼，有 TaoDBM 文件夹的才是）。

2. 快速上手

第一次打开 TaoDBM

启动后你会看到一个「开始」标签页，上面写着三步走通：新建连接 → 展开库与表 → 新建查询。

本手册就是这三步的详细版：顶栏点「手册」或随时按 F1 都能打开。

界面布局

· 顶栏：左上角 TaoDBM 图标点开是功能菜单（刷新、新建查询、查看数据、设计表、备份/还原、传输、ER 图、编辑连接、删除连接、设置、操作手册）；右侧依次是「＋ 新建连接」「主题」「手册」「关于」。

· 左侧：连接树，展开后是库、表、视图等对象。

· 中部：标签页工作区，查询、数据浏览、ER 图等都开在这里，互不干扰。

· 主题：顶栏「主题」可切换水墨 / 天青 / 墨夜三套配色。

· 就地提示：操作结果直接在界面上提示，重要告警进告警中心可回溯，不弹窗轰炸。

五分钟走通全流程

1. 点右上角「＋ 新建连接」，选数据库类型，填主机、端口、账号、密码。

2. 点「测试连接」，提示通过后保存。

3. 在左侧树展开连接 → 库 → 表，双击表即可浏览数据。

4. 选中库或表后点「新建查询」，写 SQL 按 F5 执行。

！连接生产库时建议先用只读账号，确认无误后再用高权限账号做变更。

遇到问题怎么办

· 先用「一键诊断」给连接或库做只读体检：连通性、版本、对象规模、锁等待、数据抽样，一眼定位问题层。

· 程序运行日志在本地落盘，反馈问题时把日志带上，定位更快。

· 功能入口找不到时按 F1 回到本手册，按章节找。

· 本手册也随交付包带一份网页版，不装程序双击就能看。

3. 连接管理

新建连接

· 入口：右上角「＋ 新建连接」，或左上角菜单「编辑连接」。

· 支持七种数据库：MySQL、PostgreSQL、SQL Server、SQLite、Oracle、MongoDB、Redis。

· SQLite 是文件库，选好数据库文件即可，无需主机账号。

· 填完先点「测试连接」，通过再保存，避免保存了连不上的配置。

· 新建 / 编辑连接分四个页签：「常规」放主机端口账号等核心项，「SSH 隧道」「高级」收起跳板机、哨兵等进阶配置，「备注」可写连接用途给自己看。

· 保存时哪项没填对，会自动切到对应页签提示，不会让你在页签间来回找错。

编辑与删除

· 编辑：左上角菜单「编辑连接」，改完同样先测试再保存。

· 删除：左上角菜单「删除连接」。删除只移除本机保存的连接配置，不会动数据库里的任何数据。

连接安全

· 连接配置只保存在本机，不上传到任何服务器。

· 需要跳板机访问内网库时，可配置 SSH 隧道，凭据仅在会话内使用。

！不要把生产库密码发给任何人；程序内也不会明文展示已保存的密码。

多实例并行

· 支持同时开多个实例、多窗口操作不同连接，互不干扰。

· 实例之间通过 .sql 脚本交接工作：一个实例里写好的脚本，拖到另一个实例接着跑。

分组与星标

· 连接多了可以建分组归类：树上右键「分组」新建组，把连接拖进组里管理；删组不删连接。

· 常用的连接可右键「星标」置顶，不常用的可「隐藏」收起来，树清爽不翻找。

· 分组、星标、隐藏状态都会记住，重启软件还在。

Redis 哨兵与集群

· 连接 Redis 支持三种模式：单机、哨兵（Sentinel）、集群。

· 用哨兵时填哨兵地址与 master 名称即可，主从切换后自动跟到新主库。

· 哨兵模式下端口校验按哨兵地址走，master 名称必填，保存前会检查。

4. 对象树与数据浏览

连接树

· 展开连接看到库列表，再展开库看到表、视图等对象。

· 在连接节点上点右键（或用左上角菜单）可刷新、新建查询、查看数据、设计表、备份/还原、传输、ER 图、编辑连接、删除连接。

· 树是懒加载的：点开展开才去查库，大数据量实例也不会一打开就卡。

查看数据

· 双击表打开数据浏览页，分页加载，大数据量走虚拟滚动，翻页不卡。

· 可以直接在表格里改单元格、删行；改单元格会自动留痕（见「数据安全与留痕」一章），可查差异、单条回滚；删行有确认弹窗，误删走「误删恢复」。

· 查询结果可导出 CSV / INSERT SQL，也支持流式导出大表。

看板

· 把常用查询钉在看板上，随时看最新结果与到期状态。

· 看板刷新走流式查询，不会整表物化；关掉看板即停，不后台空转。

数据浏览页里的操作

· 点列头排序，配合筛选快速定位数据；分页翻看不卡顿。

· 单元格双击就地改值、回车落库；整行编辑走弹窗逐字段确认。改动自动入留痕审计，可查差异、可单条回滚。

· 结果随手导出：CSV、INSERT SQL、Excel、XML、HTML、JSON 六种格式都支持，字段多的表也不怕。

5. SQL 查询与调试

基本操作

· 新建查询：选中库或表后点「新建查询」，或左上角菜单「新建查询」。

· 执行：F5 或 Ctrl+Enter；保存脚本：Ctrl+S；补全：Ctrl+Space。

· 输入即弹补全（默认开）：输入表名、字段名或「表名.」时自动弹出候选，无需先按 Ctrl+Space；可在「设置」里关掉，关掉后 Ctrl+Space 仍可手动唤出。

· 结果集支持排序、筛选、导出；大结果集分批拉取，不撑爆内存。

报表页

· 在查询结果上右键选「钉到报表页」，把常用查询钉成报表卡片；主菜单「报表页」随时打开。

· 卡片自动按数据选图：分类计数出柱状/直方，带日期出折线；点列名即可切换图表类型。

· 卡片上可刷新、移除；布局自动记住，重开软件还在。设置里可开关报表页入口。

断点调试

· 存储过程调试为脚手架口径：可查看例程定义、生成调试用语句模板，暂不支持真实断点与单步执行。

· 仅 MySQL 提供调试脚手架；其他库的例程可查看定义，调试入口会如实标注「暂不支持」。

危险拦截

· 执行前会自动过一遍高危检查：不带 WHERE 的 UPDATE / DELETE、全表 TRUNCATE 等会弹拦截窗。

· 拦截窗里能看到影响行数预估；确认要执行可输入目标库名解除拦截，或改用安全模式（自动加 LIMIT 分批）。

· 也可以把整份脚本粘进「高危 SQL 检查」逐条分级预检（见「数据安全与留痕」）。

长任务与脚本交接

· 长查询、大导出会进任务中心后台跑，可暂停、续跑、取消、重跑，不阻塞其他操作。

· 把 .sql 文件拖进窗口即可打开；多个实例并行时，脚本可在实例间交接，互不抢锁。

结果导出与快照

· 查询结果可导出六种格式：CSV、INSERT SQL、Excel（.xlsx）、XML、HTML、JSON；导出菜单里按需选。

· 浏览表数据时点导出，会先问清范围：只导当前页、按筛选结果导，还是全表逐页取数后导出，所见即所选。

· 导出配置：菜单里的「导出配置…」可设默认格式（菜单项会标「（默认）」）和浏览范围的默认选项；导出成功后还会按格式记住最近目录，下次对话框直接落到老地方（可在配置里关掉自动记忆）。

· CSV 自带逗号、引号、换行转义与 BOM，Excel 直接打开不乱码。

· 超大结果走流式导出，边查边写，不整包占内存；中途可取消，取消后可恢复。

· 需要把结果交给别人核对时，可打成带指纹的快照包，对方验包确认内容未被改动。

数据导入

· 支持把 CSV、JSON、xlsx 三种格式的文件导进已有表：在表数据浏览页选「导入」。

· 导入是四步向导：① 选类型与文件（可套用/删除已存的导入配置）→ ② 字段映射（点「智慧匹配全部字段」一键按列名和常见别名对上，也可逐列手改，冲突或全空会拦下来说人话）→ ③ 导入模式（首行为表头、遇错跳过还是即停，可存成配置）→ ④ 汇总确认后开始。

· 同名列自动匹配；映射好的整套配置可保存命名，下次导入直接套用，不用重对一遍。

· 导入过程有进度条，可随时取消；取消或出错时会说明已导入到第几行。

· 二进制列（blob 等）填十六进制串（如 48656C6C6F），程序会按二进制还原入库；填错会当场指出是哪一行。

6. 表设计与例程

设计表

· 选中表后点「设计表」，可视化编辑列定义（名称、类型、默认值、可空、主键等）。

· 改完先看 DDL 预览，确认无误再执行；执行前同样过危险检查。

· 工具栏还有「AI 建表」入口：AI 版接入后可直接用自然语言建表；还没接入时会提示先用「新建表」手工建。

例程管理

· 存储过程、函数、触发器统一管理：左树右码，双击节点打开定义。

· MySQL 提供调试脚手架：生成观测语句模板到查询窗口整段执行，过程内中间结果用 SELECT 观测；不支持断点、单步、步入。其他库显示定义与说明。

批量清理与拟真数据

· 批量清理：为删除类操作生成小批量分批计划（行数估算 + 逐批 SQL），默认先跑少量批次验证，逐条勾选确认后才执行，绝不静默删数据。

· 拟真数据：按表结构生成仿真测试数据，多表模式可一次铺满，开发测试不用手造数据。

改表前的好习惯

· 动手前先备份：备份向导四步走完，出问题有退路。

· 大表改结构前，把 DDL 粘进「上线审查」看一眼评分与发现，能提前排掉大部分坑。

· 执行链还有危险拦截兜底：不带 WHERE 的变更、全表清空都会被拦下来二次确认。

7. 备份与恢复

备份 / 恢复向导

· 入口：选中库或表后，左上角菜单「备份 / 还原」。

· 四步走：① 选库/表 → ② 选备份点 → ③ 选目标 → ④ 执行确认。

· 备份文件保存在你指定的本机位置，程序不代管。

恢复（高危操作）

· 恢复会覆盖目标库数据，属高危不可逆操作。

· 恢复前会展示影响范围预览，默认勾选「恢复前自动备份」；需要输入目标库名点亮「开始恢复」按钮，防手滑。

！恢复前务必确认目标库选对了；有自动备份也要看一眼备份点时间。

备份可用性演练

· 备份了不等于能恢复：演练功能把备份恢复到临时库，逐表计数与备份时点对账，出验证报告。

· 全程只碰临时库/临时副本，不动原库。建议重要备份定期演练一次。

备份计划

· 备份计划展示未来 7 天备份槽位、下次执行时间与保留清理预览。

· 清理清单只是预览参考，实际执行由任务中心触发，不会偷偷删备份。

· 计划生成后点「挂到任务中心」，到点自动执行，不用守着程序点备份；挂好的计划在任务中心→定时 SQL 里启停、删除。

· 同一个库的全量备份计划只挂一份，重复挂会拦下提醒。

备份历史与树内管理

· 展开连接后能看到「备份」子节点，里面按时间列出这个库的每次备份，最新的在最上面。

· 每条备份可右键：还原（覆盖当前库，先二次确认）、打开所在文件夹、删除。

· 备份文件被手动移走后，列表里会置灰标注「文件不在了」，账目还在，方便核对；删除记录不会动备份文件本身。

8. 数据传输与同步

传输（跨库迁移）

· 入口：左上角菜单「传输」。

· 选源连接/库/表 → 目标连接/库，可选「补结构」「传数据」，适合换库、上云、异构迁移。

· 同步配置：整套源/目标/表/选项可存成命名配置，下次打开直接加载；「挂到任务中心」后到点自动按配置执行（清空重灌模式挂账前会再确认一次），启停在任务中心→定时 SQL 管理。

数据对账

· 对同一连接下的两个库做行数与校验和比对，全程只读。

· 结论不一致时给出抽样 SQL，打开到查询窗口人工比对，程序不自动改数据。

迁移续传

· 整库迁移中断后可续传：载入清单与状态，已完成表校验、半途表续传、未动表整表拷贝。

· 续传计划支持另存 JSON，换机器也能接着跑。

迁移组合拳（建议流程）

1. 迁移前：先做一次数据对账，记下源库行数与校验和基线。

2. 迁移中：大库走传输 + 断点续传，中断不重头再来。

3. 迁移后：再做一次对账，两边一致才算迁移完成；有备份点可先做备份演练验证可恢复性。

！迁移是组合动作，单靠一步就宣布完成容易留隐患。

一键分布式部署

· 面向主从/分布式场景的部署向导：账号 → 播种 → 复制 → 探活 → 上线，五步走完。

· 目前 MySQL 先行；其他引擎不支持的部分会如实报出，不硬翻。

· SSH / 数据库凭据仅在授权会话内使用，不落盘明文。

9. ER 图

生成与编辑

· 选中库后点「ER 图」，自动加载库内表结构与外键关系成图。

· 节点可拖拽排布，布局可保存 / 打开，下次接着用。

导出

· 一键导出 PNG，直接贴进文档、评审材料。

· 「同步到数据库」先逐条列出要执行的变更，默认全勾选，去掉不想动的再执行；执行完逐条标 ✓ / ✗，动了哪条一目了然。

！ER 图是只读视图，改表结构请走「设计表」。

10. 用户与权限

权限面板

· 入口：选中连接后打开「用户与权限」。

· 内容：用户列表 + 风险发现 + 权限矩阵；能发现空密码、过宽授权等风险项。

授权与回收

· 所有授权 / 回收只生成语句草稿，弹窗预览、逐条勾选确认后才执行，执行写入审计日志。

！权限差异因库而异（MySQL 库级、PG 对象级、SQL Server 角色级），界面按最大公约数展示，方言差异见「七库方言差异速查」。

11. 分库分区分表

图形化向导

· 入口：选中表后打开「分库分区分表向导」。

· 四步式：选表 → 选拆分方式 → 选分片键 → 确认方案。

· 三种拆分策略：按范围、按哈希、按类别，全量点选，不用手写配置。

分片键怎么选

· 默认只允许主键、有索引等「有依据」的字段做分片键；确有需要可用熟手开关解锁全部字段（解锁动作写入审计日志）。

· 选了无依据字段会黄牌提醒并二次确认。

· 拿不准就用「分片键评估」：输入候选列的基数、倾斜比、谓词命中等画像，引擎给得分与建议策略，还能预演哈希/范围路由。

配套工具

· 热点倾斜检测：按负载画像判热点与冷清分片，给逐分片档位与处置建议。

· 再均衡计划：热点分片超出均值的量与冷清分片缺口贪心配对，生成搬迁清单。

· 读写路由：输入副本延迟与健康度，预演读请求该路由到哪个副本。

12. 智能工具与诊断

智能工具

· 慢查询诊断：静态规则 + 执行计划补充，指出慢在哪。

· 查询重测：同一查询多次计时取中位数，改写前后对比有依据。

一键诊断

· 面向连接 / 库的只读体检：连通性与版本、对象规模、锁等待与死锁检出、数据体检抽样。

· 全程只读，放心点。

诊断器页签

· 诊断器分进程、变量、状态三个页签：进程页看当前连接，变量页看系统变量，状态页看运行状态。

· 进程页默认每 10 秒自动刷新（可勾掉），切到别的页签就停，不空耗连接。

· 变量、状态页签在不支持的引擎上会如实标注，不装样子。

自然语言问库

· 用中文提问（如「上个月销量前十的商品」），程序确定性地解析成 SELECT，先给你看 SQL，确认后才执行。

· 解析纯本地完成，问题与表结构不出本机；「在编辑器打开」可带去查询窗口继续改。

上线审查

· 把要上线的脚本粘进来，逐条评分与发现，给「可上线 / 需复核 / 不建议」档位。

· 只审查不执行，上线动作仍由你在查询窗口自己跑。

主从与分布式管理

· 拓扑节点列表 + 复制延迟一览，主从状态心里有数。

· 暂停/恢复、重建通道、切换主库都只生成语句草稿，预览勾选确认后才执行，不直接动线上。

· 配合告警中心的复制延迟指标，延迟一超阈值就知道。

13. 告警中心与任务中心

告警中心

· 规则模板化创建：连接数、锁等待、复制延迟等指标选模板填阈值即可。

· 支持立即巡检、触发记录回溯、防轰炸合并（同类告警合并推送，不刷屏）。

· 指标采集只做各引擎真支持的部分，不支持的引擎会如实标注，不装样子。

通知送达方式

· 告警以应用内通知为主，打开程序就能看到；系统级通知默认关闭，需要时在设置里打开。

· 系统通知支持免打扰时段与同类事件节流，夜里不被吵醒，白天不被刷屏。

任务中心

· 长活（查询、导出）提交进统一队列，后台执行。

· 可查看状态、暂停/续跑、取消、重跑、快照导出；对话框关了任务照跑。

· 组合执行：勾选多条任务可按顺序一键连跑，也能存成命名组合下次重放；组合全部跑完只发一条汇总通知，不逐步刷屏。

· 命令行启动带 -run-task <定时任务Id>（可多个），程序会找到对应定时任务立即执行并把结果记回任务账。

14. 数据安全与留痕

留痕审计

· 表格里的行编辑（就地改值、编辑行弹窗）都会自动留痕，审计列表可查看改动差异。

· 单条可回滚：生成逆 SQL → 预览 → 危险确认后执行。

误删恢复

· 快照捕获当前数据（只读），误删后生成拼回草稿，逐条勾选确认才执行，执行写审计日志。

！恢复的是捕获快照之后的数据，快照之后的新改动需要人工核对。

数据脱敏

· 按列名自动推断敏感档位（手机号、证件号等），对查询结果打码预览。

· 只读预览不改库；正式导出走同一套脱敏规则。

高危 SQL 检查

· 粘贴整份脚本逐条检查，按危险 / 警告 / 通过分级展示，附行数预估 SQL。

· 只检查不执行。

快照包 / 共享包 / 团队合并

· 快照包：查询结果打包成带指纹的可校验快照，另存 JSON。

· 共享包：局域网搬运的封包与验包预演，SHA256 指纹防篡改、防截断。

· 团队合并：本地与远端条目合并预演（后写胜出），凭据键剔除留痕，不落库。

！共享包请走可信渠道传递；验包不通过不要导入。

安全好习惯

· 日常用只读账号，做变更时再切高权限账号，用完切回。

· 危险操作一律走草稿确认制：先预览、再勾选、后执行，不图快跳过预览。

· 重要库定期备份 + 定期演练，真出事时有得恢复、恢复得了。

15. 设置与主题

设置

· 关闭主窗口时：每次询问 / 最小化到托盘 / 直接退出，三种行为任选。

· 系统通知：总开关、免打扰时段、同类事件节流、按类型开关。

· 设置分「通用 / 外观 / 快捷键」三个页签：外观页换界面字体和字号（改了立即生效，可看预览），快捷键页给常用操作改绑按键，冲突会当场提醒。

主题

· 顶栏「主题」切换：水墨（默认浅色）、天青、墨夜。

· 弹窗、菜单等浮层会跟随主题，换肤后立即生效。

流式开关

· 流式通道状态在此只读展示（由环境变量决定），含含义说明与回退方法，程序不代改环境变量。

窗口与布局

· 窗口尺寸、位置、分栏宽度会记住：下次打开还是你上次的布局。

· 窗口有最小尺寸保护，缩到多小布局都不乱；中间分栏可拖动调节。

· 工作区多标签页并存，查询、浏览、ER 图各占一页，随手切换。

16. 七库方言差异速查

总则

· 方言差异的处理口径：能翻的翻、翻不了的报——程序不会把不支持的功能装作支持。

· 同一功能在不同库上的行为差异，界面会就地提示；本节是速查版。

MySQL

· 功能覆盖最全：存储过程调试脚手架、分布式部署向导、备份演练命令行恢复均支持。

· 标识符用反引号；密码类命令行走环境变量，不明文拼接。

PostgreSQL

· 权限为对象级，粒度更细；标识符用双引号（大小写敏感）。

· 备份演练走 psql 恢复，库名带引号处理。

SQL Server

· 权限为角色级；标识符用方括号。

· 备份恢复走 T-SQL（RESTORE DATABASE），建临时库前先判存。

SQLite

· 文件库：无需主机端口，选文件即用。

· 无服务端进程，备份即拷贝文件（演练会先校验文件头）。

Oracle

· 支持 11g 及以上版本；标识符默认大写。

· 部分管理视图因版本而异，诊断项以实际返回为准。

MongoDB

· 文档型：浏览以集合为单位，查询用筛选条件而非 SQL。

· 不支持 SQL 例程调试；告警指标仅限真支持的部分。

Redis

· 键值型：按库（db）浏览键，默认端口 6379。

· 无表结构概念；设计表、ER 图等结构类功能不适用。

17. 快捷键一览

全局与编辑器

· F1：打开操作手册（任何界面可用）。

· F5：执行当前查询。

· Ctrl+Enter：执行当前查询（同 F5）。

· Ctrl+S：保存脚本（仅查询页签生效）。

· Ctrl+Space：补全。

· F11：专注模式（隐藏侧栏放大编辑区，再按还原）。

· 鼠标：双击树上的表直接打开数据浏览；把 .sql 文件拖进窗口即打开脚本。

！快捷键在对应标签页获得焦点时生效；F1 全局生效。
