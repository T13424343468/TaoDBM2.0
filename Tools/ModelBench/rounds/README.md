# ModelBench 喂养轮次制度

目标：滚动通过率 ≥ 99%，单题回答 ≤ 10 秒（云真机 4 核 16G 口径）。

## 轮次机制（题库只增不减）

1. 每轮用 `python3 gen_bank2.py` 追加新组合题（函数×方言×问法×场景），
   新题从当前最大 q 编号顺延，corpus.jsonl 同步追加，历史题目永不删除。
2. 推送 main 后 ModelBench 工作流自动在云端真机（windows-latest 4vCPU/16GB）
   全量跑双模型，评分脚本输出通过率与单题耗时。
3. 达标判据：`score.py` 通过率 ≥ 99% 且全部题目 wall ≤ 10s。
4. 未达标时：分析 WRONG/EMPTY 错例 → 补 few-shot 示例或修评分归一化 → 重跑。
   不允许通过删题降通过率。
5. 循环不断增加：每轮额外扩展新维度组合（新函数、新问法、新方言特性、
   新边界场景），题库总量逐轮递增，直到老板喊停。
