# InteractionBaseline

TaoDBM 交互规范基线（2026-11-22 老板令「无损替代」）：竞品有的功能，交互范式取 Navicat / DBeaver / DataGrip / HeidiSQL 公约数；用户肌肉记忆原样可用，零学习成本。所有界面改动以本规范为唯一依据，逐条可验收。

## 1. 对象树

| 条目 | 规范 | 验收 |
| --- | --- | --- |
| 树-1 | 关系库表节点下挂列子节点（列名＋类型），展开即见字段 | 展开任意表节点出现列清单 |
| 树-2 | 连接/库/表/分类节点右键菜单均含「刷新」 | 右键任一节点可见刷新且生效 |
| 树-3 | 顶栏常驻「刷新」按钮，作用于选中节点 | 顶栏点刷新后树重载 |
| 树-4 | 右键菜单层级对齐 Navicat：打开数据 / 设计表 / 新建查询 / 刷新 / 删除 | 菜单项次序一致 |

## 2. 结果网格

| 条目 | 规范 | 验收 |
| --- | --- | --- |
| 网格-1 | 结果区撑满编辑器以下全部剩余空间，数据多时出滚动条 | 执行查询后结果区占满，无整片留白 |
| 网格-2 | 编辑器与结果区之间保留可调空间（后续批次加分割条） | 拖动后比例保持 |
| 网格-3 | 列宽按内容自适应，右键复制单元格/行/导出 | 右键菜单含复制与导出 |

## 3. SQL 编辑器

| 条目 | 规范 | 验收 |
| --- | --- | --- |
| 编辑器-1 | 输入即浮出补全候选（关键字＋表名＋列名），单击或插入补全，Esc 关闭 | 输入字母出现浮层 |
| 编辑器-2 | Ctrl+Space 手动唤起补全（保留） | 快捷键可用 |
| 编辑器-3 | F5 / Ctrl+Enter 执行 | 快捷键可用 |

## 4. 页签体系

| 条目 | 规范 | 验收 |
| --- | --- | --- |
| 页签-1 | 一切对象编辑内嵌主窗口页签（表设计、ER 图、备份），确认类对话框除外 | 无功能弹框 |
| 页签-2 | 表设计器含列/索引/外键分区，保存前出 SQL 预览 | 保存前可见 DDL |

## 5. 术语与反馈

| 条目 | 规范 | 验收 |
| --- | --- | --- |
| 术语-1 | 菜单/按钮/提示叫法对齐 Navicat（表设计器、对象列表、导出向导） | 逐条审查通过 |
| 反馈-1 | 错误一律红色（#FF4D4F 令牌），状态栏区分执行完成/失败 | 报错时状态栏不显「执行完成」 |
| 反馈-2 | 操作即时回显，长任务有进度 | 无静默等待 |

## 6. 例外边界

- AI 问答交互自有（禁思考链、规则层优先），视觉令牌与本规范统一。
- 竞品重功能（数据建模、结构同步等）以《全量功能对账表》为准，不临时扩范围。
- 连接配置导入不代存密码，凭据一律用户重输。
