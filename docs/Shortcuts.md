# Shortcuts

TaoDBM 快捷键映射表（U2 批次：对齐 Navicat / DataGrip 肌肉记忆，零学习成本）。全部快捷键以实际代码为准，新增快捷键须同步本表。

## 全局

| 快捷键 | 动作 | 说明 |
| --- | --- | --- |
| F1 | 打开操作手册 | 挂根 Grid，任何焦点下都响应 |

## 查询页签（WorkTab · Query）

| 快捷键 | 动作 | 说明 |
| --- | --- | --- |
| F5 | 执行编辑器内 SQL | 与工具栏「▶ 执行」同口径 |
| Ctrl+Enter | 执行编辑器内 SQL | DataGrip / Navicat 习惯 |
| Ctrl+Space | 手动唤起补全 | 关键字＋表名＋列名候选 |
| Esc | 关闭补全浮层 | 输入即提示的浮层随手关 |
| Ctrl+S | 保存 SQL 文件 | 有归属文件直接覆盖（UTF-8）；否则另存（可选 UTF-8 / UTF-8 BOM / GBK） |

## 表设计器页签（TableDesignerTab）

| 快捷键 | 动作 | 说明 |
| --- | --- | --- |
| — | SQL 预览实时刷新 | 预览随编辑自动更新，无需快捷键；执行走工具栏按钮＋确认框 |

## 约定

- 执行类快捷键只在查询页签生效；表数据页 F5 等价于刷新。
- 补全浮层为「输入即提示」，Ctrl+Space 保留为手动唤起入口（D-12 口径）。
